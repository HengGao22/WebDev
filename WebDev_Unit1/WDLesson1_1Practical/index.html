Web Technologies

HTML

Html which stands for HyperText Markup Language is the language for making web pages. It tells a browser what content exists on a page and how that content is organized

CSS

CSS (Cascading Style Sheets) is a stylesheet language used to control the presentation, layout, colors, and overall visual design of web pages written in HTML or XML. It is one of the core web technologies standardized by the W3C and allows developers to separate content from design for cleaner, more flexible websites.

JavaScript

JavaScript is a programming language used to create interactive web pages. It allows developers to add dynamic content, respond to user actions, and manipulate the HTML and CSS of a web page. JavaScript is widely used for client-side web development.
